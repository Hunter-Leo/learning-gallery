Run Your First Task
启动应用，通过 REST API 调用 Task

Start the Server

# 在 template/ 目录下 uv run python run.py # 输出示例： # INFO TaskApp started # Uvicorn running on 0.0.0.0:8000 # Registered tasks: # echo POST /api/echo # ping POST /api/ping # analysis POST /api/analysis # file_word_count POST /api/file_word_count

Test with Curl

# 调用 echo task（同步等待结果） curl -X POST http://localhost:8000/api/echo \ -H "Content-Type: application/json" \ -d '{"data":{"message":"hello"}}' # 响应： # { # "JobCode": "SUCCESS", # "echo": "hello" # } # 调用 ping（eager 模式，即时返回） curl -X POST http://localhost:8000/api/ping \ -H "Content-Type: application/json" \ -d '{"data":{}}'
POST /api/{task_name} 即时响应
