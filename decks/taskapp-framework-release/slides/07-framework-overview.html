Section 02 · Framework Overview
框架总览
taskapp-framework 是一个 Python 异步任务框架，将 FastAPI、FastMCP 和 Redis Queue 整合为统一的开发体验。 注册一个 Task = 自动获得 REST API + MCP Tool + 队列调度 + 文件管理。
⚡

Hybrid Tasks

@task 装饰器或 BaseTask 类，两种风格任选，灵活适配不同场景。

🔌

Auto REST/MCP

注册即用 — 自动生成 REST 端点和 MCP Tool，零配置。

📦

FileRef I/O

文件输入输出自动管理：下载 → 处理 → 上传，全生命周期托管。

🔄

Worker Scaling

基于内存阈值的自动扩缩 + 始终在线的基础 Worker。

🧪

Zero-Config Dev

TcpFakeServer 在开发模式下模拟 Redis，无需外部依赖。

🔐

Pluggable Auth

AuthProvider 接口 + BearerTokenAuth 内置实现，可自定义。

⚙️

Pydantic Config

类型安全的环境变量配置，TASKAPP_* 前缀全量覆盖。

🔧

Agent Skill

配套 coding agent skill，AI 辅助脚手架搭建和任务开发。
