Hybrid Task Registration
两种 Task 定义方式，满足不同场景需求

@task Decorator · 函数式

# 自包含模型 + 实现，适合简单任务 @task("echo", timeout=30) async def echo(input: EchoInput) -> EchoOutput: return EchoOutput( echo=input.message, ) # 注册到 app app = TaskApp() app.register_task(echo)

# 生命周期钩子 + 进度追踪，适合复杂任务 class AnalysisTask(BaseTask): name = "analysis" timeout = 120 retry_count = 2 async def run(self, input): self.update_progress(1/3) # ... task logic ... return AnalysisOutput(value=result) async def on_success(self, result, elapsed): self.logger.info("Done in %.2fs", elapsed)
