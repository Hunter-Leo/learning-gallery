Section 03 · Core Features
FileRef I/O System
文件输入输出的全生命周期自动管理，无需手动处理下载/上传

Input FileRef → 自动下载

class ProcessAudioInput(BaseModel): audio: FileRef # 远程 URL # POST {"audio": {"location": "https://..."}} # 框架自动下载到 workspace # run() 中 input.audio.location # 已经是本地路径

Output FileRef → 自动上传

# run() 中写入本地文件 result = ws.file("result.json") result.write_text(json.dumps(data)) return MyOutput( file=FileRef(location=str(result)) ) # 框架自动上传到存储后端 # 返回 signed URL

Workspace 管理

# 每个任务拥有独立 workspace ws = self.workspace file = ws.file("data.txt") # Path path = ws.path("subdir/") # Path

存储后端

● LocalFileStorage — 本地文件系统
● OpenDALStorage — S3 / R2 / GCS / Azure Blob

通过 TASKAPP_STORAGE_BACKEND 切换。WorkspaceGC 按 TTL 自动清理过期文件。
