Auto REST / MCP Endpoints
注册一个 Task，四类端点自动生成，零额外代码

REST API Endpoints

# 提交任务 POST /api/{task_name} Body: { "data": { ... }, "callback_url": "...", "wait_seconds": 0 } # 查询状态 / 结果 GET|POST /api/task_query?JobId={job_id} # 接收回调 POST /callback
# 终端测试示例 curl -X POST http://localhost:8000/api/echo \ -H "Content-Type: application/json" \ -d '{"data": {"message": "hello"}}'

MCP Tool Integration

# MCP 端点挂载到 /mcp POST /mcp # FastMCP.from_fastapi() 自动将 # 所有路由映射为 MCP Tools # AI 助手可直接调用这些工具 # 无需额外适配层

Auto-generated Typed API

每个 Task 的输入/输出 Pydantic 模型自动生成 OpenAPI Schema： Pydantic Model → OpenAPI → FastAPI Routes → MCP Tools
