Section 04 · Task Patterns
@task Decorator Pattern
函数式任务定义 — 自包含 Model + 实现，一目了然

Input / Output 模型

class EchoInput(BaseModel): message: str = Field( description="Message to echo" ) class EchoOutput(TaskResultBase): JobCode: str = "SUCCESS" echo: str

Eager 模式（跳过队列）

@task("ping", eager=True) async def ping(input: PingInput): return PingOutput( response="pong" ) # 适合：健康检查、缓存刷新
简洁 自包含 可测试

Progress 注入

# 声明 progress 参数即可获取 @task("process-data", timeout=60) async def process( input: DataRequest, progress: TaskProgress, ) -> DataResult: progress.update( "processing", 50, "Processing records..." ) return DataResult(data=await transform(input)) # 配合 app.register_task() 注册 app = TaskApp() app.register_task(process)

注册方式

app.register_task(task) app.task() 装饰器 独立 @task()
