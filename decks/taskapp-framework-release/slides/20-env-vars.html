taskapp-framework
Section 04 · Configuration
Environment Variables
全部 TASKAPP_* 环境变量一览，类型安全的 Pydantic Settings 配置
Server
TASKAPP_REDIS_URL
Redis 连接 URL。留空自动用 TcpFakeServer
默认: —
TASKAPP_HOST / TASKAPP_PORT
服务监听地址和端口
默认: 0.0.0.0:8000
Worker
TASKAPP_WORKER_TYPE
coroutine (async) / process (子进程)
默认: coroutine
TASKAPP_WORKER_MIN / _MAX
Worker 自动扩缩上下限
默认: 1 / 4
TASKAPP_WORKER_MEMORY_THRESHOLD
内存使用率触发扩缩阈值
默认: 80 (%)
TASKAPP_WORKER_SCALE_INTERVAL
Worker 检查间隔
默认: 10 (s)
Storage
TASKAPP_STORAGE_BACKEND
local / s3 / gcs / azblob / oss
默认: local
TASKAPP_STORAGE_LOCAL_ROOT
本地存储根目录
默认: ./taskapp_files
TASKAPP_STORAGE_S3_BUCKET / _ENDPOINT
S3/R2 存储配置
—

完整 .env 配置示例

# ── Server ── TASKAPP_REDIS_URL=redis://localhost:6379 TASKAPP_HOST=0.0.0.0 TASKAPP_PORT=8000 # ── Worker ── TASKAPP_WORKER_TYPE=coroutine TASKAPP_WORKER_MIN=1 TASKAPP_WORKER_MAX=4 TASKAPP_WORKER_MEMORY_THRESHOLD=80 # ── Storage (Local) ── TASKAPP_STORAGE_BACKEND=local TASKAPP_STORAGE_LOCAL_ROOT=./data TASKAPP_STORAGE_LOCAL_SECRET_KEY=change-me # ── Logging ── TASKAPP_LOG_LEVEL=INFO TASKAPP_LOG_JSON=true TASKAPP_LOG_CONSOLE=true # ── MCP ── TASKAPP_MCP_ENABLED=true TASKAPP_MCP_PATH=/mcp # ── Workspace ── TASKAPP_WORKSPACE_DIR=/tmp/taskapp TASKAPP_WORKSPACE_TTL=3600 # ── App ── TASKAPP_NAME=my-service # AUTH_TOKEN=sk-xxx （应用级）
