Section 03 · Core Features
Eager Execution + Wait-and-Return
灵活的执行模式：快速任务跳过队列，慢速任务支持同步等待

Eager=True · 即时执行

# ping 任务跳过队列，inline 执行 @task("ping", timeout=5, eager=True) async def ping(input: PingInput) -> PingOutput: return PingOutput(response="pong") # POST /api/ping → 即时响应 # 无需排队，无需 Worker
零延迟 同步返回

Wait_seconds=N · 同步等待

# 提交并等待结果（最长 60 秒） POST /api/analysis { "data": { ... }, "wait_seconds": 15 } # 任务在 N 秒内完成 ➔ 直接返回结果 # 超时 ➔ 返回 job_id，客户端轮询
灵活 降级轮询

两种模式配合使用：快速幂等操作走 eager，耗时任务用 wait-and-return 降低客户端复杂度。
