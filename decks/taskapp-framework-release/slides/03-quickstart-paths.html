Section 01 · Quick Start
Choose Your Path
两种方式上手，选一种开始
OPTION A

手动部署

克隆仓库 → 配置 → 手动启动

01 git clone https://cnb.cool/mirabobio.com/demostration/taskapp-framework.git
02 cd taskapp-framework && uv sync
03 cp .env.example .env
04 vim .env # 按需配置
05 uv run python run.py
OPTION B

Agent Skill

安装 skill，让 AI 处理搭建

01 npx skills add "https://cnb.cool/mirabobio.com/demostration/taskapp-framework.git"
02 告诉 AI 助手：
/taskapp-development
Scaffold a service named 'my-service'
AI 将自动执行：目录检查 → 脚手架 → uv sync → .env 配置
完成后进入下一页「运行第一个 Task」
