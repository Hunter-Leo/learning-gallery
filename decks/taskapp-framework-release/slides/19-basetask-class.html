BaseTask Class Pattern
完整的生命周期钩子 + 进度追踪 + Logger，适合复杂业务任务

生命周期方法

class FileWordCountTask(BaseTask): name = "file_word_count" timeout = 60 async def run(self, input): ws = self.workspace text = open(input.file.location).read() result = ws.file("result.json") result.write_text(json.dumps({ "count": len(text.split()) })) return FileWordCountOutput( result_file=FileRef( location=str(result) ) )

钩子 + 进度 + Log

# Success 钩子 async def on_success(self, result, elapsed_seconds=0.0): self.logger.info( "Completed in %.2fs", elapsed_seconds ) # Failure 钩子 async def on_failure(self, error): self.logger.error( "Failed: %s", error ) # Timeout 钩子 async def on_timeout(self): self.logger.warning( "Task timed out" )

run() 支持 async def 和 def 两种风格，框架自动检测。
