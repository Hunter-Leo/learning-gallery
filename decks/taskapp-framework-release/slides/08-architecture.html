Execution Pipeline

所有执行路径（worker / eager / in-memory test）都通过同一套 execute_task_with_lifecycle() 共享流水线。
FastAPI — 自动生成 REST 端点
FastMCP — 自动生成 MCP Tools
TaskManager — 队列调度 + 自动扩缩
FileRef — 文件输入输出自动管理
AuthProvider — 可插拔认证
Workspace — 任务临时工作目录 + GC

Task Lifecycle

QUEUED → STARTED → (DOWNLOADING → UPLOADING) → FINISHED
             → FAILED / TIMEOUT / CANCELED
