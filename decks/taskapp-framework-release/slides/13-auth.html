Pluggable Authentication
通过 AuthProvider 抽象接口实现可插拔认证，健康检查端点自动绕过

内置实现：BearerTokenAuth

from taskapp_core.server.auth import BearerTokenAuth # 一行开启 Bearer Token 认证 app = TaskApp( title="MyApp", auth=BearerTokenAuth( token="sk-..." ), ) # 请求需携带头 # Authorization: Bearer sk-...

未认证请求返回 401。GET / 健康检查自动放行。

自定义 AuthProvider

class CustomAuth(AuthProvider): async def authenticate( self, request: Request ) -> AuthResult: # 从 header / cookie / query 验证 api_key = request.headers.get( "X-API-Key" ) if is_valid(api_key): return AuthResult( authenticated=True ) return AuthResult( authenticated=False ) # 使用自定义认证 app = TaskApp(auth=CustomAuth())

实现 AuthProvider 抽象类即可，open/closed 原则。
