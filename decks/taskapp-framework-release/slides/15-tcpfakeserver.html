Section 03 · Core Features
Zero-Config Development
TcpFakeServer — 无需 Redis 即可本地开发的秘密武器

工作原理

# 不设置 REDIS_URL 时自动启用 # TcpFakeServer 监听本地端口 # 模拟 Redis 协议的子集： # · LPUSH / BRPOP / BLPOP # · GET / SET / DEL / EXISTS # · SMEMBERS / SADD / SREM # · ZADD / ZREMRANGEBYSCORE # · EXPIRE # 完全在内存中运行 # 进程重启数据即清除

开发 vs 生产

  • 本地开发 — 不设 REDIS_URL，零依赖开箱即用
  • CI / 测试 — InMemoryTaskExecutor + fakeredis，无需基础设施
  • 生产 — 设置 TASKAPP_REDIS_URL，自动切换真实 Redis
    • # 生产 .env 一行启用 Redis TASKAPP_REDIS_URL=redis://localhost:6379/0

    开发与生产无缝切换，同一套代码无需任何改动。
