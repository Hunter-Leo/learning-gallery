Agents：专门化子代理

Agent 是在独立上下文中运行的专门化 AI 实例，处理特定任务后返回摘要，不污染主对话

agents/code-reviewer.md

description: Expert code review specialist
model: opus
tools: [Read, Grep, Glob, Bash]
maxTurns: 20

---
 
你是一位专业的代码审查专家。
重点检查：安全漏洞、性能问题、
代码可读性和最佳实践。
model
haiku / sonnet / opus
isolation
worktree 隔离执行
tools
限制可用工具集
maxTurns
最大执行轮次
Agent 执行流程
1
Claude 识别任务，决定派发给 Agent
2
Agent 在独立上下文中启动，加载自己的指令
3
Agent 使用分配的工具自主执行任务（多轮）
4
任务完成，Agent 返回摘要给主对话
5
主对话继续进行，上下文保持干净
