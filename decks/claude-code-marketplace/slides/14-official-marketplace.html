提交你的 Plugin 到官方目录

通过官方提交表单，经过质量和安全审核后，Plugin 会被列入 external_plugins/ 目录。

1.创建 Plugin 并推送到 GitHub 公开仓库
2.确保 plugin.json 包含完整元数据（description、keywords、homepage）
3.在 clau.de/plugin-directory-submission 提交申请
4.等待 Anthropic 团队审核质量和安全标准
5.审核通过后，Plugin 出现在官方 Marketplace

企业私有 Marketplace

组织内部分发

企业可搭建私有 Marketplace，通过 managed settings 的 enabledPlugins 强制分发经过审核的 Plugin，确保团队使用统一、安全的扩展集合。
