Plugin Manifest：plugin.json

plugin.json 是 Plugin 的身份证，定义名称、版本、组件路径和元数据

.claude-plugin/plugin.json
{
  "name": "code-quality", // kebab-case，命名空间
  "version": "1.2.0",
  "description": "Code quality tools for teams",
  "author": "your-github-handle",
  "license": "MIT",
 
  // 组件路径（相对 plugin 根目录）
  "skills": "./skills/",
  "agents": "./agents/",
  "hooks": "./hooks/hooks.json",
  "commands": "./commands/",
  "mcpServers": {
    "github": { /* ... */ }
  },
 
  // Marketplace 元数据
  "keywords": ["code-quality", "review"],
  "homepage": "https://github.com/you/code-quality"
}
name 必填
kebab-case 格式，成为所有组件的命名空间前缀。用户调用时输入 /code-quality:review
version 必填
语义化版本号，Marketplace 用于追踪更新和自动升级
skills / agents / hooks 可选
各组件的路径，可以是目录或具体文件。未指定则使用默认目录名
mcpServers 可选
内联 MCP 配置对象，或指向外部配置文件路径
keywords / homepage 可选
Marketplace 展示用，帮助用户搜索和发现你的 Plugin
