Marketplace · 分发层

一个 marketplace.json 文件托管在 Git 仓库，提供集中发现、版本追踪和自动更新。用户通过 /plugin marketplace add 订阅。

P

Plugin · 打包层

自包含目录，将所有组件打包成可安装单元。命名空间隔离，多个 Plugin 共存不冲突。通过 /plugin install 安装。

5

五类组件 · 能力层

Skills（工作流）、Agents（子代理）、Hooks（自动化）、Commands（斜杠命令）、MCP Servers（外部服务）——每类解决不同问题。
