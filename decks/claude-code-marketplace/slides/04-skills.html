Chapter 03 · Skills

Skills：可复用的工作流模板

Skill 是一个 Markdown 文件，包含知识、工作流或指令，可通过命令调用或由 Claude 自动加载

skills/review/SKILL.md
---
name: code-review
description: Review code for quality and security
triggers:
  - review
  - code quality
tools: [Read, Grep, Glob]
---
 
# Code Review Skill
 
当用户请求代码审查时，执行以下步骤：
 
1. 读取目标文件，分析代码质量
2. 检查安全漏洞（OWASP Top 10）
3. 评估性能瓶颈
4. 输出结构化报告
S

Frontmatter 控制行为

通过 YAML frontmatter 定义触发词、可用工具、描述，Claude 会在合适时机自动加载

/

斜杠命令调用

用户输入 /plugin-name:skill-name 直接调用，或 Claude 根据上下文自动触发

↗

隔离执行

Skill 可在当前对话运行，也可通过 subagent 在独立上下文中执行，保护主对话窗口

H

内嵌 Hooks

Skill frontmatter 中可定义 Hooks，仅在该 Skill 激活期间生效

调用方式
/my-plugin:code-review
# 或 Claude 自动识别触发词
