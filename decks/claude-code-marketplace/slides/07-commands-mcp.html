Chapter 06 · Commands & MCP

Commands 与 MCP Servers

Commands 是用户直接调用的斜杠命令；MCP 是连接外部服务的标准协议层

Commands · 斜杠命令
commands/generate-tests.md
---
description: Generate unit tests for selected code
argument-hint: "[file-path]"
---
 
为 $ARGUMENTS 中的文件生成完整的
单元测试，覆盖边界情况和错误路径。
/

命名空间调用

用户输入 /my-plugin:generate-tests src/auth.ts

$

参数传递

通过 $ARGUMENTS 接收用户输入的参数

≡

Skill vs Command

Command 是扁平 .md 文件；Skill 是含 SKILL.md 的目录，功能更丰富

MCP Servers · 外部服务连接
plugin.json → mcpServers
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "${GITHUB_TOKEN}"
      }
    }
  }
}
⚡

标准协议

MCP 是 Anthropic 开放的工具调用协议，任何服务都可接入

⊕

Plugin 内置

Plugin 安装后，MCP Server 自动注册，无需用户手动配置

⊞

常见用途

GitHub、Jira、Slack、数据库、内部 API 等外部系统集成
