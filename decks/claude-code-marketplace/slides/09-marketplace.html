Chapter 08 · Marketplace

创建 Marketplace

一个 marketplace.json + 一个 Git 仓库，即可搭建可订阅、可自动更新的插件分发平台

1

创建 Plugin

构建包含 Skills、Agents、Hooks、MCP 的 Plugin，确保 plugin.json 元数据完整

2

创建 marketplace.json

定义插件目录，列出每个 Plugin 的 Git 来源、分类和标签

3

托管到 GitHub / GitLab

推送到公开或私有 Git 仓库，Marketplace 通过 git clone 分发

4

用户订阅

用户运行 /plugin marketplace add <repo-url> 订阅，在 Discover 标签页浏览安装

5

自动更新

启用 auto-update 后，Claude Code 启动时自动拉取最新版本，提示 /reload-plugins

marketplace.json
{
  "name": "my-team-marketplace",
  "description": "Team plugins catalog",
  "plugins": [
    {
      "name": "code-quality",
      "description": "Code review tools",
      "source": {
        "type": "git",
        "url": "https://github.com/you/code-quality"
      },
      "category": "development",
      "tags": ["review", "quality"],
      "version": "1.2.0"
    }
  ]
}
# 用户订阅你的 Marketplace /plugin marketplace add github.com/you/marketplace
企业用途：管理员通过 enabledPlugins 在 managed settings 中强制启用 Plugin，通过私有 Marketplace 统一分发经过审核的扩展，确保团队安全合规。
