Chapter 02 · Plugin

Plugin：扩展的打包容器

Plugin 是一个自包含目录，将 Skills、Agents、Hooks、MCP 打包成可安装、可分发的单元

什么是 Plugin？

Plugin 是 Claude Code 的扩展单元。安装后，它的 Skills 自动出现在命令列表，Hooks 自动注册，Commands 变成斜杠命令。

命名空间隔离

Plugin 的 Skills 和 Commands 自动加上命名空间前缀，如 /my-plugin:review，多个 Plugin 可以共存不冲突。

安装方式

通过 /plugin install <repo-url> 安装，或从 Marketplace 的 Discover 标签页一键安装。

关键规则：只有 plugin.json 放在 .claude-plugin/ 目录内。Skills、Hooks、Agents 等所有其他文件放在 Plugin 根目录。
