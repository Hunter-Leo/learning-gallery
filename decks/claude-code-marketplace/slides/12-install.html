Chapter 11 · Install & Manage

安装与管理 Plugin

通过 /plugin 命令管理 Plugin 和 Marketplace 的完整生命周期

Plugin 管理
/plugin install <repo-url>
从 Git 仓库安装 Plugin，支持 GitHub / GitLab / 本地路径
/plugin list
列出所有已安装的 Plugin 及版本
/plugin update [name]
更新指定 Plugin 或所有 Plugin 到最新版本
/plugin uninstall <name>
卸载 Plugin，移除所有注册的组件和 Hooks
Marketplace 管理
/plugin marketplace add <url>
订阅一个 Marketplace，拉取插件目录
/plugin marketplace update
刷新所有 Marketplace 的插件目录
/reload-plugins
更新后重新加载所有 Plugin，使变更生效

Discover 标签页

在 Claude Code 中运行 /plugin 打开 Discover 标签页，可视化浏览官方 Marketplace 的所有插件，一键安装。

自动更新

为 Marketplace 启用 auto-update 后，Claude Code 每次启动时自动检查并更新已安装的 Plugin，有更新时提示运行 /reload-plugins。

本地开发安装

开发阶段可用本地路径安装：/plugin install ./my-plugin，无需推送到远程仓库即可测试。

官方 Marketplace (claude-plugins-official) 在 Claude Code 启动时自动可用，无需手动添加。访问 claude.com/plugins 查看完整目录。
