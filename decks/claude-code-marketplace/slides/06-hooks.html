Chapter 05 · Hooks

Hooks：生命周期自动化

Hooks 是在 Claude Code 生命周期特定节点自动执行的脚本，提供对行为的确定性控制

PreToolUse
工具执行前触发，可阻止危险操作
PostToolUse
工具成功后触发，执行后续动作（如格式化）
UserPromptExpansion
用户提交前，向 prompt 注入额外上下文
SubagentStart / Stop
子代理启动/停止时触发，监控并行任务
SessionStart
会话开始时注入项目上下文或环境信息
hooks/hooks.json
{
  "hooks": [
    {
      "event": "PreToolUse",
      "matcher": {
        "tool": "Bash",
        "input": "git push"
      },
      "command": "./scripts/pre-push.sh",
      "type": "blocking"
    },
    {
      "event": "PostToolUse",
      "matcher": { "tool": "Write" },
      "command": "prettier --write $FILE"
    }
  ]
}
