Chapter 10 · Priority & Layers

优先级与层级覆盖

同名组件存在多个来源时，Claude Code 按固定优先级决定哪个生效

Skills / Agents 优先级（高 → 低）
#1
CLI Flag
--skill 参数
↓ 被覆盖
#2
Project
.claude/
↓ 被覆盖
#3
User
~/.claude/
↓ 被覆盖
#4
Plugin
已安装插件

Skills / Agents：名称覆盖

同名组件按优先级「赢者通吃」——高优先级的定义完全替换低优先级的。项目级 Skill 可以覆盖 Plugin 提供的同名 Skill。

Hooks：全部触发

Hooks 不存在覆盖关系。所有来源（用户、项目、Plugin、Skill frontmatter）的 Hooks 都会注册，匹配事件时全部触发。

CLAUDE.md：向上合并

子目录的 CLAUDE.md 与父目录合并，不覆盖。Plugin 的 CLAUDE.md 追加到全局上下文，不替换用户的配置。
