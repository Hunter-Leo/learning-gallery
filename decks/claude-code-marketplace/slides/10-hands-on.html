实战：从零构建一个 Plugin

以「代码质量检查 Plugin」为例，完整走一遍创建、测试、发布流程

bash — ~/code-quality-plugin
$ mkdir code-quality-plugin && cd $_
$ mkdir -p .claude-plugin skills/review agents hooks commands
 
$ cat > .claude-plugin/plugin.json <<EOF
{ "name": "code-quality", "version": "1.0.0" }
EOF
 
$ git init && git add . && git commit -m "init"
✓ Initialized empty Git repository
 
$ git push origin main
✓ Pushed to github.com/you/code-quality
 
# 在 Claude Code 中安装测试
/plugin install github.com/you/code-quality
✓ Plugin installed: code-quality v1.0.0
01

搭建目录结构

创建 .claude-plugin/、skills/、agents/、hooks/ 目录

02

编写 plugin.json

填写 name（kebab-case）、version、description，声明组件路径

03

添加 Skill

在 skills/review/SKILL.md 写入 frontmatter + 指令内容

04

添加 Hook

在 hooks/hooks.json 配置 PreToolUse 阻止危险 git push

05

本地安装测试

用 /plugin install ./local-path 本地安装，验证功能

06

推送并发布到 Marketplace

推送到 GitHub，在 marketplace.json 中添加条目，通知用户更新
