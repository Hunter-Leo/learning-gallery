Installation & Quick Start

安装与快速开始

S
Superpowers
Plugin Marketplace 安装
# Claude Code 2.0.13+ 通过插件市场安装
/plugin install superpowers
  • 安装后自动激活，无需手动配置
  • 在 CLAUDE.md 中添加 superpowers section
  • 新任务自动触发 brainstorming 流程
快速开始
直接开始新任务，Claude 会自动进入 brainstorming 模式提问
G
gstack
Git clone + setup
# 克隆到 skills 目录
git clone https://github.com/garrytan/gstack.git \
  ~/.claude/skills/gstack

# 运行 setup
cd ~/.claude/skills/gstack && ./setup
  • 在 CLAUDE.md 添加 gstack section
  • 列出可用 skills: /plan-ceo-review 等
  • 可选：复制到项目 .claude/skills/ 共享给团队
快速开始
/plan-ceo-review 开始 CEO 视角审视新功能
O
oh-my-claudecode
Plugin Marketplace 安装
# 通过插件市场安装
/plugin install oh-my-claudecode

# 或手动安装
git clone https://github.com/yeachan-heo/\
  oh-my-claudecode.git ~/.claude/skills/omc
  • 安装后运行 /omc-setup 初始化
  • 选择运行模式：Team / Autopilot / Ralph
  • 32 个 agents 自动可用
快速开始
/team "实现用户认证系统" 开始 Team 模式
E
everything-claude-code
选择性安装
# 完整安装
/plugin install everything-claude-code

# 或选择性安装（推荐新用户）
cp -r everything-claude-code/.agents/skills/* \
  ~/.claude/skills/
  • 推荐：先安装 core/general skills
  • 按需添加 domain skills（Python/React/AWS）
  • 配置 hooks.json 启用 TDD/安全扫描
快速开始
/skill-create 从 git 历史生成新 skill
