Selection Guide

选型指南 · 如何选择适合你的插件

S
Superpowers
流程驱动 · 纪律之师
推荐

适合需要严格流程控制的单人开发者或小团队。强制 TDD + 代码审查，让每个功能都经过完整验证。

  • 中大型项目，需要高代码质量
  • 想要「虚拟团队」的审查机制
  • 愿意遵循 brainstorm → plan → implement 流程
  • 需要 git worktrees 隔离工作区
G
gstack
角色切换 · CEO 工作流

适合创业团队或需要 CEO 视角的开发者。8 个角色显式控制，每个阶段独立决策。

  • Web 应用，需要浏览器自动化测试
  • 产品决策需要 CEO 视角审视
  • 想要显式控制每个阶段，而非自动化
  • Garry Tan 的粉丝，想用他的工作流
O
oh-my-claudecode
多智能体 · 团队引擎
推荐

适合团队协作或需要多智能体并行的场景。32 个专业 agent，Team 模式五阶段流水线。

  • 团队协作，需要任务分配和协同
  • 大型项目，需要并行处理多个任务
  • 想要「零学习曲线」的 Claude Code 体验
  • 需要多种运行模式（Team / Autopilot / Ralph）
E
everything-claude-code
企业级 · 全栈方案

适合企业团队或需要全栈能力覆盖的项目。156 skills + 持续学习，覆盖主流技术栈。

  • 企业团队，需要全栈能力
  • 多技术栈项目，需要领域专业支持
  • 长期项目，需要持续学习积累
  • 需要生产级 hooks 和安全扫描
快速决策
单人 + 需要纪律 → Superpowers  |  创业 + CEO 视角 → gstack  |  团队 + 并行协作 → oh-my-claudecode  |  企业 + 全栈覆盖 → everything-claude-code
