Plugin #1

Superpowers · 流程驱动的纪律之师

核心理念

Superpowers 的核心哲学是「强制流程」——不是让 Claude 自由发挥，而是通过 14 个 skills 强制执行 brainstorm → plan → implement 的标准流程。

关键约束：如果 Claude 尝试在测试之前写实现代码，Superpowers 会强制删除代码并重新开始。
标准工作流
01
brainstorming
Socratic 式提问，探索需求边界，输出设计文档
02
using-git-worktrees
创建隔离工作区，新分支 + 独立目录
03
writing-plans
拆分为 2-5 分钟任务，每个任务含文件路径 + 验证步骤
04
executing-plans
每个任务派发独立 subagent，两阶段审查
05
test-driven-development
RED-GREEN-REFACTOR 循环，强制测试先行
14 个核心 Skills
brainstorming writing-plans executing-plans test-driven-development requesting-code-review receiving-code-review using-git-worktrees finishing-a-development-branch dispatching-parallel-agents verification-before-completion systematic-debugging writing-skills subagent-driven-development using-superpowers
适合场景
  • ✓ 中大型项目，需要严格的代码质量
  • ✓ 团队协作，需要可预测的开发流程
  • ✓ 新功能开发，需要从设计到交付的完整链路
  • ✓ 单人开发者，想要「虚拟团队」的审查机制
