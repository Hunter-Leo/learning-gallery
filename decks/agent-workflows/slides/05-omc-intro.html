核心理念

OMC (oh-my-claudecode) 是目前最流行的 Claude Code 插件（30K+ stars），核心是「多智能体协同」——让多个专业 agent 在共享任务列表上并行工作，像真实团队一样分工协作。

核心差异：不是单人工作流，而是团队编排。Team 模式下，plan-prd-exec-verify-fix 五阶段流水线，每个阶段由不同 agent 负责。
Team 模式流水线
1
team-plan
Planner agent 分析需求，输出任务分解
2
team-prd
Architect agent 设计技术方案，输出 PRD
3
team-exec
多个 Executor agent 并行实现不同任务
4
team-verify
Verifier agent 检查实现是否符合 PRD
5
team-fix
Fixer agent 修复 verify 发现的问题
